## 이 사이트의 사용법

이 사이트는 세 개의 트랙과 두 개의 학습 장치로 구성된다.

**커리큘럼**은 개념의 뼈대다. "인공지능이란 무엇인가"에서 시작해 학습 이론, 머신러닝, 딥러닝, 생성 모델, LLM, 강화학습, 에이전트, 그리고 이를 받치는 수학과 컴퓨터 과학까지 28개의 강의로 이어진다. 처음 공부한다면 여기서 시작한다.

**핸드북**은 이론의 근거다. 각 주제를 한 줄 정의 → 문제 상황 → 직관 → 수식 유도 → 구현 → 실무 관점 → 핵심 정리의 일곱 단계로 파고든다. 커리큘럼에서 개념을 잡은 뒤, 같은 주제의 핸드북 문서로 내려가 수식으로 확인한다.

**코드랩**은 손의 훈련이다. NumPy 역전파부터 GPT·Diffusion·PPO 밑바닥 구현, LoRA 파인튜닝·RAG·에이전트, 그리고 서빙까지 — 처음부터 끝까지 실행되는 완전한 코드로 CV·NLP·생성모델·RL·멀티모달 전 도메인을 관통한다. 이 트랙을 마치면 AI 코드를 읽는 사람이 아니라 쓰는 사람이 된다.

**로드맵**은 세 트랙을 잇는 지도다. 8단계 학습 경로마다 어떤 강의·문서·코드랩을 함께 볼지 짝지어 놓았다.

**복습 퀴즈**는 기억의 장치다. 각 영역을 마칠 때마다 퀴즈로 점검한다. 답을 보기 전에 스스로 답해 보고, 맞힘/복습 기록을 남겨 약한 부분만 다시 돈다.
