# 1부 퀴즈. 기계가 배운다는 것

범위: [1장](/book/01-what-is-ai) ~ [4장](/book/04-generalization)

<QuizProgress prefix="p1" :total="12" />

<Quiz id="p1-01" q="전통적 프로그래밍과 머신러닝의 차이를 '넣는 것'과 '나오는 것'으로 설명하라.">

**답:** 전통적 프로그래밍은 `규칙 + 데이터 → 답`이고, 머신러닝은 `데이터 + 답 → 규칙(모델)`이다. 규칙을 사람이 적을 수 없는 문제(할 줄은 알지만 설명 못 하는 일)에서 예시로부터 규칙을 역으로 찾게 한다. → [1장](/book/01-what-is-ai)

</Quiz>

<Quiz id="p1-02" q="'학습한다'의 공학적 정의를 작업·성능·경험으로 말하라. 이 정의가 실용적 나침반이 되는 이유는?">

**답:** 어떤 작업에 대해, 어떤 성능 지표로 재었을 때, 경험(데이터)이 쌓일수록 성능이 좋아지면 학습하는 것이다. 이 정의는 모든 AI 프로젝트의 첫 세 질문 — 작업이 무엇인가, 무엇으로 잴 것인가, 데이터는 어디서 오는가 — 를 담고 있다. → [1장](/book/01-what-is-ai)

</Quiz>

<Quiz id="p1-03" q="지도·비지도·강화·자기지도 학습을 '주어지는 신호'로 구분하라.">

**답:** 지도학습은 정답, 비지도학습은 데이터만, 강화학습은 보상, 자기지도학습은 데이터의 일부를 가려 만든 자체 정답(다음 단어 가리기 등 — GPT의 방식). → [1장](/book/01-what-is-ai)

</Quiz>

<Quiz id="p1-04" q="학습 기계의 세 부품(모델·손실·최적화)을 집값 예제로 설명하라.">

**답:** 모델은 답의 모양을 정한 후보 집합($\hat{y} = wx+b$, 파라미터 $w,b$), 손실은 '잘 맞음'을 숫자로 만든 채점표(평균제곱오차), 최적화는 손실을 낮추는 파라미터를 찾는 절차(경사하강). 학습 = 손실을 최소화하는 파라미터 찾기. → [2장](/book/02-first-learning-machine)

</Quiz>

<Quiz id="p1-05" q="경사하강법의 갱신 규칙을 쓰고, 학습률이 너무 클 때와 작을 때 각각 무슨 일이 생기는지 말하라.">

**답:** $w \leftarrow w - \eta \,\partial L/\partial w$ — 기울기 반대 방향으로 학습률만큼 이동. 너무 크면 골짜기를 건너뛰며 발산(NaN), 너무 작으면 골짜기에 닿지 못하고 정체. 발산의 첫 용의자는 언제나 학습률이다. → [2장](/book/02-first-learning-machine)

</Quiz>

<Quiz id="p1-06" q="내적의 두 얼굴은 무엇이며, 각각 이 책의 어디에서 주인공이 되는가?">

**답:** 가중합(선형 모델의 예측 계산)과 닮음의 측정(같은 방향일수록 큼 — 코사인 유사도). 후자는 임베딩의 의미 검색과 어텐션의 관련도 계산에서 주인공이 된다. → [3장](/book/03-math-for-learning)

</Quiz>

<Quiz id="p1-07" q="연쇄법칙을 톱니바퀴 비유로 설명하고, 이것이 역전파와 기울기 소실에 어떻게 연결되는지 말하라.">

**답:** 겹친 함수의 민감도는 단계별 민감도의 곱이다(페달→체인→바퀴의 회전비 곱). 역전파는 이 곱을 층별로 조직한 알고리즘이고, 곱의 구조 때문에 1보다 작은 민감도를 수십 번 곱하면 기울기가 소실된다. → [3장](/book/03-math-for-learning)

</Quiz>

<Quiz id="p1-08" q="'손실 함수는 발명이 아니라 도출'이라는 말의 뜻을 제곱오차를 예로 설명하라.">

**답:** 최대가능도 원리 — 관측된 데이터가 나올 확률이 가장 높은 파라미터를 고른다 — 에서 손실이 나온다. 오차가 정규분포로 흩어진다고 가정하면 그 원리가 제곱오차로, 출력이 확률이면 교차 엔트로피로 도출된다. → [3장](/book/03-math-for-learning)

</Quiz>

<Quiz id="p1-09" q="훈련 오차 0이 축하할 일이 아닐 수 있는 이유를 설명하라.">

**답:** 진짜 목표는 처음 보는 데이터에 대한 성능(일반화)이다. 훈련 데이터를 통째로 외운 모델도 훈련 오차는 0이지만 새 데이터에서 무너진다(과적합). 훈련 성적만으로는 외운 학생과 이해한 학생을 구분할 수 없다. → [4장](/book/04-generalization)

</Quiz>

<Quiz id="p1-10" q="편향과 분산은 각각 무엇이며, 모델 용량을 키우면 어떻게 움직이는가?">

**답:** 편향은 모델이 단순해서 생기는 체계적 오차, 분산은 훈련 데이터가 바뀔 때 모델이 흔들리는 정도. 용량을 키우면 편향은 줄고 분산은 는다 — 과소적합↔과적합 스펙트럼의 수학. 데이터가 많을수록 큰 용량을 감당한다. → [4장](/book/04-generalization)

</Quiz>

<Quiz id="p1-11" q="검증 집합과 테스트 집합을 분리해야 하는 이유는?">

**답:** 검증 성적으로 모델을 수십 번 고르다 보면 검증 집합에 과적합한다(검증 집합이 우연히 좋아한 선택을 골라 온 것). 한 번도 의사결정에 쓰지 않은 테스트 집합만이 공정한 최종 추정을 준다. 테스트로 모델을 고치는 순간 테스트가 아니다. → [4장](/book/04-generalization)

</Quiz>

<Quiz id="p1-12" q="데이터 누수의 대표적 두 경로와 처방을 말하라.">

**답:** ① 전처리(정규화 등)를 전체 데이터로 계산한 뒤 나누기 → 전처리는 훈련 집합만으로 계산해 적용. ② 시계열을 무작위로 섞어 나누기 → 과거로 훈련, 미래로 검증. 누수는 개발 중 성적을 부풀리고 배포 후 청구서를 낸다. → [4장](/book/04-generalization)

</Quiz>
