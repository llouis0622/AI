# 6부 퀴즈. 생성

범위: [19장](/book/19-generative-models) ~ [20장](/book/20-diffusion)

<QuizProgress prefix="p6" :total="10" />

<Quiz id="p6-01" q="판별 모델과 생성 모델이 배우는 것을 확률로 구분하고, '무작위 픽셀은 왜 얼굴이 안 되는가'를 설명하라.">

**답:** 판별은 $p(y|x)$, 생성은 $p(x)$ 자체를 배워 새 표본을 뽑는다. 말이 되는 이미지는 고차원 공간의 지극히 얇은 영역에만 사므로 무작위 점이 그 영역에 떨어질 확률은 0 — 생성 모델은 그 영역의 지도를 배운다. → [19장](/book/19-generative-models)

</Quiz>

<Quiz id="p6-02" q="VAE 손실의 두 항과 각각을 빼면 무너지는 것은?">

**답:** 복원 오차(본질을 담아라)와 분포 벌점 KL(잠재 공간을 표준 정규 근처로 정돈하라). 벌점을 빼면 잠재 공간에 빈틈이 생겨 생성 시 쓰레기가 나오고, 복원 항을 빼면 아무것도 담지 않는다. → [19장](/book/19-generative-models)

</Quiz>

<Quiz id="p6-03" q="VAE 결과가 흐릿한 이유는?">

**답:** 픽셀 평균 기반 복원 오차는 '여러 그럴듯한 답의 평균'을 내놓도록 모델을 밀고, 날카로운 디테일의 평균은 흐림이다. → [19장](/book/19-generative-models)

</Quiz>

<Quiz id="p6-04" q="GAN의 천재성과 대가를 각각 한 문장으로.">

**답:** '그럴듯함'의 채점을 학습되는 판별기에 위탁해 날카로운 결과를 얻는다. 대가는 밥그릇 최적화가 아닌 2인 게임의 불안정 — 판별기가 너무 강하면 신호가 사라지고, 얌체 전략은 모드 붕괴(같은 것만 생성)를 낳는다. → [19장](/book/19-generative-models)

</Quiz>

<Quiz id="p6-05" q="GPT는 어떤 종류의 생성 모델이며, 텍스트에 그 방식이 맞는 이유는?">

**답:** 자기회귀 — $p(x)$를 조건부 분포의 곱으로 분해해 각 조각을 분류 문제로 배운다. 텍스트는 시퀀스로 자연히 분해되므로 이 길이 완벽히 맞는다. 데이터 구조가 생성 전략을 고른다. → [19장](/book/19-generative-models)

</Quiz>

<Quiz id="p6-06" q="확산 모델의 발상을 '파괴'와 '복원'으로 설명하라.">

**답:** 파괴(노이즈를 천 번 더해 백색소음으로)는 우리가 설계해 배울 것이 없다. 복원(조금 덜 흐리게 하기)은 걸작 그리기가 아닌 작은 청소라 배우기 쉽다. 생성은 순수 노이즈에서 복원을 역재생하는 것. → [20장](/book/20-diffusion)

</Quiz>

<Quiz id="p6-07" q="확산 모델의 학습 문제는 정확히 무엇이며, 왜 GAN보다 안정적인가?">

**답:** 임의 시점의 노이즈 낀 이미지와 시점 $t$를 주고 '섞인 노이즈를 맞혀라' — 제곱오차의 순수 회귀 문제. 게임도 두 항의 줄다리기도 없어 바위처럼 안정적이며, 단계별 작은 교정이라 평균의 저주도 비켜간다. → [20장](/book/20-diffusion)

</Quiz>

<Quiz id="p6-08" q="노이즈 예측기에 시점 t를 알려 줘야 하는 이유는?">

**답:** $t=10$(거의 깨끗)과 $t=900$(거의 노이즈)에서 걷어내야 할 노이즈의 강도가 전혀 다르다. 지금 얼마나 망가진 상태인지 알아야 얼마나 청소할지 정할 수 있다. → [20장](/book/20-diffusion)

</Quiz>

<Quiz id="p6-09" q="잠재 확산이 해결한 문제와 분업 구조는?">

**답:** 고해상도 픽셀 공간에서 천 걸음은 너무 비싸다. 오토인코더로 작게 압축한 잠재 공간에서 확산을 돌리고 디코더로 픽셀을 복원 — 지각적 디테일은 오토인코더가, 내용 생성은 확산이 맡는다(Stable Diffusion). → [20장](/book/20-diffusion)

</Quiz>

<Quiz id="p6-10" q="텍스트로 생성을 조종하는 두 부품은?">

**답:** 텍스트 임베딩을 노이즈 예측기에 교차 어텐션으로 주입하는 조건화, 그리고 '텍스트 준 예측'과 '안 준 예측'의 차이 방향을 과장해 걷는 안내 증폭(classifier-free guidance) — 충실도 다이얼이되 과하면 다양성이 죽는다. → [20장](/book/20-diffusion)

</Quiz>
