# 5부 퀴즈. 언어

범위: [16장](/book/16-tokens-and-embeddings) ~ [18장](/book/18-transformer)

<QuizProgress prefix="p5" :total="12" />

<Quiz id="p5-01" q="단어 단위·글자 단위 토큰화의 문제와 서브워드(BPE)의 원리는?">

**답:** 단어 단위는 어휘가 무한해 모르는 단어(OOV)에 벙어리가 되고, 글자 단위는 의미가 없고 너무 길다. BPE는 바이트에서 출발해 가장 자주 붙는 인접 쌍을 병합하는 규칙을 반복 학습 — 자주 쓰는 단어는 통째로, 드문 단어는 조각으로. 모르는 단어가 사라진다. → [16장](/book/16-tokens-and-embeddings)

</Quiz>

<Quiz id="p5-02" q="LLM이 철자 세기에 약하고 한국어에서 비용 손해를 보는 현상을 토큰화로 설명하라.">

**답:** 모델은 글자가 아니라 토큰 덩어리를 본다. 학습 데이터에 적은 언어는 토큰이 잘게 쪼개져 같은 내용에 토큰이 더 들고(비용·컨텍스트 손해), 성능도 떨어진다. → [16장](/book/16-tokens-and-embeddings)

</Quiz>

<Quiz id="p5-03" q="토큰 번호를 그대로 신경망에 넣으면 안 되는 이유와 임베딩의 해법은?">

**답:** 번호의 크기·거리에는 의미가 없는데 신경망은 숫자의 크기로 계산한다. 토큰마다 학습되는 벡터를 배정하고(임베딩 행렬), '문맥으로 단어 맞추기' 과제가 비슷한 문맥의 단어 벡터를 가깝게 만든다(분포 가설). → [16장](/book/16-tokens-and-embeddings)

</Quiz>

<Quiz id="p5-04" q="임베딩 공간에서 '거리는 유사도, 방향은 관계'라는 말을 예로 설명하라.">

**답:** 고양이·강아지 벡터는 가깝다(유사도). 왕−남자+여자≈여왕처럼 성별 같은 관계가 일관된 방향으로 표현된다. 이 기하학이 키워드 없이 통하는 의미 검색과 추천을 가능하게 한다. → [16장](/book/16-tokens-and-embeddings)

</Quiz>

<Quiz id="p5-05" q="RNN의 두 벽을 말하고, 둘의 공통 원인을 짚어라.">

**답:** 먼 기억의 소실(민감도 곱의 사슬)과 직렬성(병렬화 불가). 공통 원인: 정보가 이웃 단계를 사슬처럼 통과해서만 전달된다. → [17장](/book/17-rnn-to-attention)

</Quiz>

<Quiz id="p5-06" q="어텐션의 세 단계를 쿼리·키·밸류로 설명하라.">

**답:** ① 쿼리와 모든 키의 내적으로 관련도 측정, ② 소프트맥스로 합이 1인 주목 가중치, ③ 밸류의 가중 평균 — 문맥이 반영된 새 벡터. Q/K/V 변환 자체가 학습되어 무엇을 묻고 어떻게 색인되고 무엇을 건넬지를 데이터가 정한다. → [17장](/book/17-rnn-to-attention)

</Quiz>

<Quiz id="p5-07" q="어텐션이 RNN의 두 벽을 무너뜨린 방식과, 그 대가는?">

**답:** 모든 단어가 모든 단어를 직접 참조하므로 거리가 사라지고, 관련도 계산이 행렬 곱 하나라 완전 병렬이다. 대가는 단어 수 제곱의 비용 — 긴 문맥이 LLM의 기술적 난제인 이유. → [17장](/book/17-rnn-to-attention)

</Quiz>

<Quiz id="p5-08" q="위치 인코딩이 필요한 이유를 가중 평균의 성질로 설명하라.">

**답:** 가중 평균은 순서를 모른다 — '개가 사람을 물었다'와 '사람이 개를 물었다'는 단어 집합이 같아 구별 불가. RNN은 순서대로 읽어 공짜로 얻던 순서를, 어텐션은 위치 벡터 덧셈이나 회전(RoPE)으로 명시적으로 새겨야 한다. → [17장](/book/17-rnn-to-attention)

</Quiz>

<Quiz id="p5-09" q="Transformer 블록의 두 하위 층과 각각의 역할, 그리고 감겨 있는 두 무기는?">

**답:** 멀티헤드 어텐션(토큰 사이의 정보 교환)과 피드포워드 망(토큰 각자의 정보 가공). 각각에 잔차 연결과 층 정규화. 이 블록의 반복이 전부이며 새 부품은 없다. → [18장](/book/18-transformer)

</Quiz>

<Quiz id="p5-10" q="BERT류·GPT류·인코더-디코더의 차이는 무엇 하나로 결정되는가?">

**답:** 마스킹 — 어텐션이 어디까지 보게 허용하느냐. 양방향(이해 과제), 인과적(왼쪽만 — 생성, 전 위치 병렬 학습), 인코더(양방향)+디코더(인과+교차 어텐션)(변환 과제). → [18장](/book/18-transformer)

</Quiz>

<Quiz id="p5-11" q="인과 마스크가 '천 토큰 문장 = 천 개의 병렬 학습 문제'를 가능하게 하는 이유는?">

**답:** 각 위치가 자기 이전만 보므로, 문장을 한 번 통과시키면 모든 위치가 동시에 '각자의 다음 토큰 맞추기'를 풀 수 있다. 미래를 보면 커닝이 되어 학습이 무너진다. 훈련은 병렬, 생성은 직렬이라는 비대칭이 여기서 나온다. → [18장](/book/18-transformer)

</Quiz>

<Quiz id="p5-12" q="이 책의 부품으로 GPT를 한 문장에 정의하라.">

**답:** 토큰 임베딩 + 위치 정보 + 인과 마스크 Transformer 디코더 블록 N개 + 어휘 소프트맥스로, 다음 토큰의 조건부 분포를 출력하는 모델. 학습은 교차 엔트로피 + 역전파 + AdamW — 2장 이후 바뀐 것이 없다. → [18장](/book/18-transformer)

</Quiz>
