# 복습 퀴즈

읽기만 한 지식은 빠르게 사라진다. 답을 보기 전에 **스스로 답해 보는 것**(능동 회상)이 가장 효율적인 복습이다. 각 문항에서 먼저 답을 떠올린 뒤 "정답 보기"로 확인하고, 결과를 "맞혔다 / 다시 복습"으로 기록한다. 기록은 이 브라우저에만 저장되며, 페이지 상단의 진행 바에서 현황을 확인할 수 있다.

권장 사이클: 한 부를 마친다 → 그 부의 퀴즈를 푼다 → "다시 복습" 문항의 답에 링크된 장을 다시 읽는다 → 며칠 뒤 그 퀴즈만 다시 푼다.

| 퀴즈 | 범위 |
| --- | --- |
| [1부. 기계가 배운다는 것](/review/quiz-part1) | 1~4장 — 학습의 정의, 모델·손실·최적화, 수학 도구, 일반화 |
| [2부. 고전 머신러닝](/review/quiz-part2) | 5~8장 — 분류, 트리와 앙상블, 비지도, 평가 |
