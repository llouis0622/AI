# 복습 퀴즈

읽기만 한 지식은 빠르게 사라진다. 답을 보기 전에 **스스로 답해 보는 것**(능동 회상)이 가장 효율적인 복습이다. 각 문항에서 먼저 답을 떠올린 뒤 "정답 보기"로 확인하고, 결과를 "맞혔다 / 다시 복습"으로 기록한다. 기록은 이 브라우저에만 저장되며, 페이지 상단의 진행 바에서 현황을 확인할 수 있다.

권장 사이클: 로드맵의 한 단계를 마친다 → 해당 퀴즈를 푼다 → "다시 복습" 문항의 답에 링크된 문서를 다시 읽는다 → 며칠 뒤 그 퀴즈만 다시 푼다.
