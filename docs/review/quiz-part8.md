# 8부 퀴즈. 행동

범위: [25장](/book/25-reinforcement-learning) ~ [26장](/book/26-policy-gradient)

<QuizProgress prefix="p8" :total="10" />

<Quiz id="p8-01" q="강화학습 문제를 지도학습과 구별하는 두 성질은?">

**답:** 보상이 지연되고 드문드문 주어진다(정답이 아니라 결과), 그리고 행동이 다음 상황을 바꿔 어떤 데이터를 보게 될지가 자신에게 달렸다. → [25장](/book/25-reinforcement-learning)

</Quiz>

<Quiz id="p8-02" q="MDP의 다섯 요소와 리턴(할인 누적 보상)에서 할인율의 두 역할은?">

**답:** 상태·행동·전이·보상·할인율. 할인은 무한 합의 발산을 막고, 같은 보상이면 빨리 받는 게 낫다는 상식을 심는다. → [25장](/book/25-reinforcement-learning)

</Quiz>

<Quiz id="p8-03" q="Q-학습의 갱신식을 쓰고, '한 걸음 뒤에 본 목표'가 어떻게 학습 신호가 되는지 설명하라.">

**답:** $Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma\max_{a'}Q(s',a') - Q(s,a)]$. 지금 가치는 '보상 + 다음 상태 최선 가치의 할인'이어야 한다는 재귀(벨만)를 임시 정답 삼아 고친다. 종착점의 진실이 거꾸로 한 칸씩 전파된다. → [25장](/book/25-reinforcement-learning)

</Quiz>

<Quiz id="p8-04" q="탐색-활용 딜레마와 ε-탐욕의 처방은?">

**답:** 아는 최선만 고르면 더 나은 행동을 영영 못 찾고, 새 것만 시도하면 보상을 놓친다. 확률 ε로 무작위 행동을 섞되 점점 줄인다. 지도학습에는 없는 RL 고유의 딜레마. → [25장](/book/25-reinforcement-learning)

</Quiz>

<Quiz id="p8-05" q="DQN의 두 장치가 각각 깨진 '지도학습의 전제'를 대응시켜 설명하라.">

**답:** 재생 버퍼 — 연속 경험은 상관되어 있어 독립 표본 가정이 깨지므로 섞어 뽑는다. 목표 네트워크 — 학습 목표가 자기 자신으로 계산되어 움직이므로 복사본으로 잠시 고정한다. → [25장](/book/25-reinforcement-learning)

</Quiz>

<Quiz id="p8-06" q="'에이전트는 의도가 아니라 보상의 문자를 최적화한다'의 예를 들고, 이것이 이 책의 어떤 교훈과 같은 뿌리인지 말하라.">

**답:** '빨리 가라'에 넘어지며 구르기, 점수 보상에 버그 찾기. 8장의 지표 최적화≠목표 달성, 22장의 채점기 해킹과 같은 뿌리 — 원하는 것을 정확히 적는 일이 가장 어렵다. → [25장](/book/25-reinforcement-learning)

</Quiz>

<Quiz id="p8-07" q="가치 기반 방법이 막히는 두 상황과 정책 경사의 발상은?">

**답:** 연속 행동(argmax 불가)과 확률적 정책이 필요한 경우(가위바위보). 정책을 직접 확률 분포로 파라미터화하고, 기대 리턴의 기울기로 올라간다. → [26장](/book/26-policy-gradient)

</Quiz>

<Quiz id="p8-08" q="환경을 미분할 수 없는데 어떻게 정책의 기울기를 얻는가?">

**답:** 표본 추정 — '그 행동을 택할 로그확률의 기울기 × 그 뒤 실제로 얻은 리턴'을 평균낸다. 결과가 좋았던 행동은 확률을 높이고 나빴던 행동은 낮추되 결과 크기에 비례해서. 환경이 준 점수를 가중치로 쓴다. → [26장](/book/26-policy-gradient)

</Quiz>

<Quiz id="p8-09" q="기준선과 이점(advantage)이 분산을 줄이는 원리는?">

**답:** 절대 리턴 대신 '평균보다 얼마나 나았나'(리턴 − 상태 가치)로 밀면, 모든 행동이 좋은 상황에서 전부 밀어 올리는 낭비가 사라진다. 기대값은 변하지 않으므로 편향 없는 분산 감소. 가치를 배우는 크리틱을 붙인 것이 액터-크리틱. → [26장](/book/26-policy-gradient)

</Quiz>

<Quiz id="p8-10" q="PPO 클리핑의 동작과, RLHF에서 RL 개념들의 실체를 대응시켜라.">

**답:** 새/옛 정책 확률 비율을 [1−ε, 1+ε]로 잘라 '좋은 방향으로도 한 번에 조금만' — 붕괴 방지와 데이터 재사용. RLHF: 상태=프롬프트+생성 토큰, 행동=다음 토큰, 정책=LLM, 보상=보상 모델 점수−KL 벌점, 알고리즘=PPO. → [26장](/book/26-policy-gradient)

</Quiz>
