# 퀴즈 01. 인공지능 기초

범위: [Lecture 01~05](/curriculum/ch01/lecture01) — 인공지능의 정의, 학습의 개념, 학습 패러다임, 일반화, 편향과 분산.

<Quiz id="fd-01" q="규칙 기반 시스템과 학습 기반 시스템의 근본적 차이를 입력과 출력의 관계로 설명하라.">

**답:** 규칙 기반은 `규칙 + 데이터 → 답`으로, 사람이 규칙을 직접 작성한다. 학습 기반은 `데이터 + 답 → 규칙(모델)`로, 데이터에서 규칙을 자동으로 학습한다. 규칙 기반은 규칙 폭발과 예외 처리의 한계가 있고, 학습 기반은 데이터 의존성과 해석의 어려움이 따른다. → [Lecture 01](/curriculum/ch01/lecture01)

</Quiz>

<Quiz id="fd-02" q="AI, 머신러닝, 딥러닝의 포함 관계와 각각의 정의를 말하라.">

**답:** AI ⊃ ML ⊃ DL. AI는 지능적 작업의 자동화를 다루는 가장 넓은 범주, ML은 명시적 규칙 없이 데이터로부터 패턴을 학습하는 AI의 한 분야, DL은 인공 신경망의 층을 깊게 쌓아 점진적으로 복잡한 표현을 학습하는 ML의 한 분야다. → [Lecture 01](/curriculum/ch01/lecture01)

</Quiz>

<Quiz id="fd-03" q="Mitchell(1997)의 학습 정의를 T, P, E로 서술하라.">

**답:** 어떤 작업 $T$에 대해 성능 $P$로 측정했을 때, 경험 $E$로 인해 성능이 향상된다면 그 프로그램은 $T$에 대해 $E$로 학습한 것이다. 즉 학습은 "측정 가능한 성능 향상"으로 정의된다. → [Lecture 02](/curriculum/ch01/lecture02)

</Quiz>

<Quiz id="fd-04" q="지도학습, 비지도학습, 강화학습을 감독 신호의 형태로 구분하라.">

**답:** 지도학습은 입력-정답 쌍(레이블)이 주어진다. 비지도학습은 레이블 없이 데이터의 구조(군집, 밀도, 표현)를 스스로 찾는다. 강화학습은 정답 대신 행동의 결과로 주어지는 보상 신호로부터 학습한다. 자기지도학습은 데이터 자체에서 감독 신호를 만들어내는 방식으로, 레이블 비용 문제를 우회한다. → [Lecture 03](/curriculum/ch01/lecture03)

</Quiz>

<Quiz id="fd-05" q="일반화란 무엇이며, 훈련 오차가 낮은데 테스트 오차가 높은 상황을 무엇이라 부르는가?">

**답:** 일반화는 훈련에 쓰지 않은 새로운 데이터에서도 좋은 성능을 내는 능력이다. 훈련 오차는 낮은데 테스트 오차가 높으면 과적합(overfitting) — 모델이 데이터의 일반적 패턴이 아니라 훈련 집합의 노이즈까지 외운 상태다. 반대로 둘 다 높으면 과소적합이다. → [Lecture 04](/curriculum/ch02/lecture04)

</Quiz>

<Quiz id="fd-06" q="편향(bias)과 분산(variance)은 각각 어떤 오차를 뜻하며, 왜 트레이드오프가 생기는가?">

**답:** 편향은 모델의 표현력 부족으로 생기는 체계적 오차(평균 예측과 진짜 함수의 차이), 분산은 훈련 데이터가 바뀔 때 예측이 흔들리는 정도다. 기대 오차는 편향² + 분산 + 줄일 수 없는 노이즈로 분해된다. 모델 용량을 키우면 편향은 줄지만 데이터에 민감해져 분산이 커지므로 트레이드오프가 생긴다. → [Lecture 05](/curriculum/ch02/lecture05)

</Quiz>

<Quiz id="fd-07" q="강인공지능과 약인공지능을 구분하고, 현재 모든 AI 시스템이 어디에 속하는지 말하라.">

**답:** 강인공지능은 사람과 구분하기 어려운 범용 지능으로 아직 실현되지 않았다. 약인공지능은 특정 분야에서 사람을 보조하는 지능으로, 현재의 모든 AI 시스템이 여기에 속한다. → [Lecture 01](/curriculum/ch01/lecture01)

</Quiz>

<Quiz id="fd-08" q="검증 집합(validation set)과 테스트 집합(test set)의 역할 차이는 무엇인가?">

**답:** 검증 집합은 하이퍼파라미터 선택과 모델 비교 등 학습 과정의 의사결정에 쓴다. 테스트 집합은 모든 결정이 끝난 뒤 최종 일반화 성능을 한 번 측정하는 용도다. 테스트 집합을 반복적으로 들여다보며 결정에 쓰면 사실상 검증 집합이 되어 성능 추정이 낙관적으로 오염된다. → [Lecture 04](/curriculum/ch02/lecture04)

</Quiz>

<Quiz id="fd-09" q="모델 용량(capacity)을 늘리는 것 외에, 과적합을 줄이는 대표적인 방법 세 가지를 들어라.">

**답:** 데이터를 늘리기(증강 포함), 정규화(L2, 드롭아웃, 조기 종료 등)로 유효 용량을 제한하기, 검증 성능 기반의 모델 선택. 핵심은 훈련 데이터의 노이즈까지 외울 자유를 줄이는 것이다. → [Lecture 04](/curriculum/ch02/lecture04), [Lecture 05](/curriculum/ch02/lecture05)

</Quiz>

<Quiz id="fd-10" q="현대 AI가 Task-oriented라는 말의 의미를 설명하라.">

**답:** 현대 AI는 "지능 그 자체"를 구현하기보다 특정 과제(분류, 번역, 생성 등)를 정의하고, 그 과제의 측정 가능한 성능을 올리는 방식으로 설계된다. 과제 정의(T), 평가 지표(P), 데이터(E)가 시스템 설계의 출발점이 된다. → [Lecture 01](/curriculum/ch01/lecture01), [Lecture 02](/curriculum/ch01/lecture02)

</Quiz>
