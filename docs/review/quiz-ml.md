<Quiz id="ml-01" q="경험적 위험 최소화(ERM)란 무엇이며, 왜 진짜 위험 대신 경험적 위험을 최소화하는가?">

**답:** 진짜 위험(기대 손실)은 데이터 분포를 모르므로 계산할 수 없다. 그래서 훈련 데이터에 대한 평균 손실인 경험적 위험 $\hat{R}(\theta) = \frac{1}{N}\sum_i \ell(f_\theta(x_i), y_i)$을 대신 최소화한다. 표본이 충분하고 모델 용량이 적절하면 경험적 위험이 진짜 위험에 근접하지만, 그 간극이 곧 일반화 오차다. → [Lecture 06](/curriculum/ch03/lecture06)

</Quiz>

<Quiz id="ml-02" q="L1 정규화와 L2 정규화의 효과 차이와 그 기하학적 이유를 설명하라.">

**답:** L1(라쏘)은 가중치를 정확히 0으로 만들어 희소성을 유도하고, L2(릿지)는 가중치를 0 쪽으로 고르게 줄이지만 0으로 만들지는 않는다. L1의 제약 영역(마름모)은 꼭짓점이 축 위에 있어 최적해가 축(일부 좌표 0)에 닿기 쉽고, L2의 제약 영역(원)은 그렇지 않기 때문이다. → [핸드북 Part 03 · 07편](/handbook/03-machine-learning/07-regularization)

</Quiz>

<Quiz id="ml-03" q="데이터 누수(data leakage)란 무엇이며 대표적인 발생 경로 두 가지를 들어라.">

**답:** 훈련 시점에 접근할 수 없어야 할 정보(테스트/미래 정보)가 학습에 스며들어 성능이 부풀려지는 현상이다. 대표 경로: (1) 전처리(스케일링, 결측 대체 등)를 분할 전에 전체 데이터로 적합시키는 것, (2) 시계열에서 미래 정보가 특징에 포함되거나 무작위 분할로 미래가 훈련에 섞이는 것. → [핸드북 Part 03 · 03편](/handbook/03-machine-learning/03-validation-and-data-leakage)

</Quiz>

<Quiz id="ml-04" q="정밀도(precision)와 재현율(recall)의 정의를 말하고, 어떤 상황에서 어느 쪽을 우선하는지 예를 들어라.">

**답:** 정밀도 = TP/(TP+FP), 양성 예측 중 실제 양성 비율. 재현율 = TP/(TP+FN), 실제 양성 중 잡아낸 비율. 스팸 필터처럼 오탐(정상 메일 차단)이 치명적이면 정밀도를, 암 진단처럼 놓침이 치명적이면 재현율을 우선한다. 둘의 조화평균이 F1이다. → [핸드북 Part 03 · 04편](/handbook/03-machine-learning/04-evaluation-metrics)

</Quiz>

<Quiz id="ml-05" q="로지스틱 회귀는 무엇을 모델링하며, 손실함수로 무엇을 쓰는가?">

**답:** 입력의 선형결합을 시그모이드에 통과시켜 양성 클래스의 확률 $p(y=1|x) = \sigma(w^\top x + b)$을 모델링한다. 손실은 베르누이 가능도의 음의 로그인 교차엔트로피(로그 손실)이며, MLE 관점에서 유도된다. 제곱오차를 쓰지 않는 이유는 시그모이드와 결합하면 비볼록이 되고 그래디언트가 포화되기 때문이다. → [핸드북 Part 03 · 06편](/handbook/03-machine-learning/06-logistic-regression)

</Quiz>

<Quiz id="ml-06" q="SVM의 마진 최대화가 의미하는 바와 커널 트릭의 핵심을 설명하라.">

**답:** SVM은 두 클래스를 가르는 초평면 중 가장 가까운 샘플(서포트 벡터)까지의 거리(마진)를 최대화하는 것을 찾는다 — 마진이 클수록 일반화가 좋다는 직관이다. 커널 트릭은 쌍대 문제가 내적에만 의존한다는 점을 이용해, 명시적 고차원 매핑 없이 커널 함수 $K(x, x')$로 비선형 결정 경계를 얻는 기법이다. → [핸드북 Part 03 · 09편](/handbook/03-machine-learning/09-svm)

</Quiz>

<Quiz id="ml-07" q="배깅과 부스팅의 차이를 분산/편향 관점에서 설명하라.">

**답:** 배깅(랜덤포레스트)은 부트스트랩 표본으로 독립적인 모델들을 병렬 학습해 평균냄으로써 **분산**을 줄인다 — 과적합하기 쉬운 깊은 트리에 적합하다. 부스팅(GBDT)은 이전 모델의 오차(잔차/그래디언트)를 순차적으로 보정하는 약한 학습기를 더해 **편향**을 줄인다 — 얕은 트리를 많이 쌓는다. → [핸드북 Part 03 · 11~12편](/handbook/03-machine-learning/11-bagging-and-random-forest)

</Quiz>

<Quiz id="ml-08" q="k-means의 목적함수와 알고리즘 두 단계, 그리고 대표적 한계를 말하라.">

**답:** 각 클러스터 내 샘플과 중심 간 거리 제곱합(관성)을 최소화한다. (1) 할당 단계: 각 점을 가장 가까운 중심에 배정, (2) 갱신 단계: 각 클러스터의 평균으로 중심 이동 — 수렴까지 반복(EM의 특수형). 한계: k를 미리 정해야 하고, 구형·비슷한 크기의 클러스터를 가정하며, 초기화에 민감하다(k-means++로 완화). → [핸드북 Part 03 · 14편](/handbook/03-machine-learning/14-clustering-and-em)

</Quiz>

<Quiz id="ml-09" q="PCA는 무엇을 최대화(또는 최소화)하는 방향을 찾으며, 어떤 행렬 분해로 계산하는가?">

**답:** 투영된 데이터의 분산을 최대화하는(동치로, 재구성 오차를 최소화하는) 직교 방향들을 찾는다. 공분산 행렬의 고유값 분해, 또는 중심화된 데이터 행렬의 SVD로 계산하며, 상위 고유벡터(특이벡터)가 주성분이 된다. → [핸드북 Part 03 · 15편](/handbook/03-machine-learning/15-dimensionality-reduction)

</Quiz>

<Quiz id="ml-10" q="k-겹 교차검증은 언제, 왜 쓰는가? 시계열 데이터에서는 어떻게 달라져야 하는가?">

**답:** 데이터가 적어 단일 검증 분할의 추정 분산이 클 때, 데이터를 k등분해 각 폴드를 한 번씩 검증에 쓰고 평균내어 안정적인 성능 추정을 얻는다. 시계열에서는 무작위 분할이 미래 누수를 만들므로, 훈련 구간 뒤에 검증 구간이 오는 전진(rolling/expanding) 분할을 써야 한다. → [핸드북 Part 03 · 03편](/handbook/03-machine-learning/03-validation-and-data-leakage)

</Quiz>

<Quiz id="ml-11" q="결정트리는 분기 기준을 어떻게 고르며, 왜 단일 트리는 과적합하기 쉬운가?">

**답:** 각 분기에서 불순도(지니, 엔트로피) 감소 또는 분산 감소가 최대가 되는 특징·임계값을 탐욕적으로 고른다. 깊이 제한 없이 자라면 잎마다 소수 샘플까지 완벽 분리해 훈련 데이터를 외우게 되므로(높은 분산) 과적합한다 — 가지치기, 깊이/잎 크기 제한, 또는 앙상블로 완화한다. → [핸드북 Part 03 · 10편](/handbook/03-machine-learning/10-decision-trees)

</Quiz>

<Quiz id="ml-12" q="테이블 데이터 실무에서 GBDT(XGBoost/LightGBM)가 여전히 기본 선택지인 이유를 두 가지 이상 들어라.">

**답:** (1) 중소 규모 테이블 데이터에서 딥러닝보다 성능이 좋거나 비슷하면서 학습이 훨씬 빠르고 튜닝이 쉽다. (2) 특징 스케일링이 불필요하고 결측·범주형 처리가 견고하다. (3) 특징 중요도 등 해석 수단이 있다. 이질적 특징(나이, 금액, 카테고리 혼재)에서는 트리의 축-정렬 분기가 강한 귀납 편향이 된다. → [핸드북 Part 03 · 13편](/handbook/03-machine-learning/13-gbdt-libraries-and-ensembling)

</Quiz>
