# 2부 퀴즈. 고전 머신러닝

범위: [5장](/book/05-classification) ~ [8장](/book/08-evaluation)

<QuizProgress prefix="p2" :total="12" />

<Quiz id="p2-01" q="로지스틱 회귀에서 시그모이드의 역할은 무엇이며, 결정 경계는 어떤 모양인가?">

**답:** 선형 점수($wx+b$)를 0~1의 확률로 번역하는 통역사. 점수 0이 확률 0.5. 결정 경계는 점수=0인 곳이므로 언제나 직선(고차원에선 평면)이다. → [5장](/book/05-classification)

</Quiz>

<Quiz id="p2-02" q="교차 엔트로피 손실을 한 문장으로 정의하고, 정답 확률 0.9와 0.01일 때의 벌점을 비교하라.">

**답:** 정답에 부여한 확률의 $-\log$. $-\log 0.9 \approx 0.1$, $-\log 0.01 \approx 4.6$ — 확신에 찬 오답을 극형으로 다스린다. 최대가능도에서 도출된다. → [5장](/book/05-classification)

</Quiz>

<Quiz id="p2-03" q="소프트맥스의 정의와 온도의 효과를 말하라.">

**답:** $p_k = e^{z_k}/\sum_j e^{z_j}$ — 점수들을 합이 1인 확률 분포로. 온도 $T$로 점수를 나누면 $T$가 클수록 분포가 평평해져 다양한 선택, 작을수록 승자 독식. LLM API의 temperature가 이것이다. → [5장](/book/05-classification)

</Quiz>

<Quiz id="p2-04" q="kNN이 '학습 없는' 모델인 이유와, 그럼에도 표현(벡터화)에 크게 의존하는 이유는?">

**답:** 훈련 데이터를 저장했다가 이웃 다수결로 답하므로 학습 단계가 없다. 하지만 '가깝다'의 정의가 성능을 지배하고, 고차원에서는 모든 점이 비슷하게 멀어져(차원의 저주) 좋은 표현 없이는 이웃이 무의미하다. → [5장](/book/05-classification)

</Quiz>

<Quiz id="p2-05" q="결정 트리는 각 갈림길의 질문을 어떤 기준으로 고르며, 왜 혼자 두면 과적합하는가?">

**답:** 쪼갠 뒤 각 갈래의 불순도(뒤섞임)가 가장 많이 줄어드는 질문을 탐욕적으로 고른다. 제한 없이 자라면 잎마다 훈련 데이터 한둘만 남을 때까지 쪼개 통째로 암기한다 — 고분산 모델의 전형. → [6장](/book/06-trees-and-ensembles)

</Quiz>

<Quiz id="p2-06" q="배깅과 부스팅의 전략 차이를 편향·분산의 언어로 설명하라.">

**답:** 배깅(랜덤 포레스트)은 깊은 트리들을 무작위 표본으로 독립 학습해 평균 — 분산을 깎는다. 부스팅은 얕은 트리가 이전 오차(잔차)를 순차 보완 — 편향을 깎는다. 후자는 함수 공간의 경사하강이라 그래디언트 부스팅이라 부른다. → [6장](/book/06-trees-and-ensembles)

</Quiz>

<Quiz id="p2-07" q="테이블 데이터에서 GBDT가 여전히 기본 선택인 이유를 말하라.">

**답:** 테이블의 열은 이질적이고 공간 구조가 없어, '연봉 ≥ 5천?' 같은 절단식 질문(트리의 언어)이 자연스러운 가설 형태다. 빠르고, 결측치에 강하고, 특징 중요도를 준다. 어림법: 이미지·음성·텍스트는 딥러닝, 테이블은 GBDT부터. → [6장](/book/06-trees-and-ensembles)

</Quiz>

<Quiz id="p2-08" q="k-평균의 두 단계와, 사용 시 기억할 세 가지 성격을 말하라.">

**답:** 배정(가장 가까운 중심에 소속)↔갱신(무리 평균으로 중심 이동)의 반복. 성격: $k$는 사람이 정한다, 둥근 무리를 가정한다, 거리가 의미 있으려면 표준화가 필수다. → [7장](/book/07-unsupervised)

</Quiz>

<Quiz id="p2-09" q="PCA가 찾는 방향은 무엇이며, '분산이 정보'인 이유는?">

**답:** 투영했을 때 데이터가 가장 넓게 퍼지는(분산 최대) 방향들. 퍼짐이 곧 개체들을 구별해 주는 정보이기 때문이다. 앞쪽 몇 축만 남겨 압축하며, 보존한 분산 비율이라는 성적표가 붙는다. → [7장](/book/07-unsupervised)

</Quiz>

<Quiz id="p2-10" q="희귀병 검진(양성 0.2%)에서 정확도 99.8% 모델이 무의미할 수 있는 이유와, 대신 봐야 할 두 지표는?">

**답:** '무조건 정상'이라 답해도 99.8%다 — 불균형에서 정확도는 다수 클래스 찍기 성적일 뿐. 정밀도(판정한 것 중 진짜 비율)와 재현율(실제 양성 중 잡아낸 비율)로 쪼개 본다. 둘의 균형은 실수의 비용이 정한다. → [8장](/book/08-evaluation)

</Quiz>

<Quiz id="p2-11" q="판정 임계값을 낮추면 정밀도와 재현율은 각각 어느 쪽으로 움직이는가? 모델 비교와 임계값 조정은 어떻게 분리하나?">

**답:** 낮추면 재현율↑ 정밀도↓(수상하면 다 양성 판정). 모델은 임계값 무관 지표(AUC류)로 비교해 고르고, 임계값은 업무 비용에 맞춰 별도로 정한다. → [8장](/book/08-evaluation)

</Quiz>

<Quiz id="p2-12" q="자기기만을 막는 실험 규율 세 가지를 들어라.">

**답:** ① 검증 성적의 작은 차이를 믿지 말고 시드를 바꿔 반복해 평균±편차로 판단. ② 기준선(다수결 찍기, 단순 모델) 없이 성적을 말하지 않기. ③ 평균 뒤에 숨은 부분집합(클래스·그룹별) 확인. 그리고 틀린 사례 30개를 직접 읽기. → [8장](/book/08-evaluation)

</Quiz>
