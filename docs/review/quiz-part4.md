# 4부 퀴즈. 지각

범위: [13장](/book/13-cnn) ~ [15장](/book/15-audio)

<QuizProgress prefix="p4" :total="10" />

<Quiz id="p4-01" q="MLP가 모르는 이미지의 두 가지 상식과, CNN이 그것을 구조로 새긴 방식은?">

**답:** ① 가까운 픽셀끼리 관련이 깊다 → 필터가 작은 지역만 본다(지역성). ② 패턴은 위치를 가리지 않는다 → 같은 필터로 온 화면을 훑는다(가중치 공유). 좋은 귀납 편향을 주입해 적은 데이터로 잘 일반화한다. → [13장](/book/13-cnn)

</Quiz>

<Quiz id="p4-02" q="합성곱 층의 파라미터 수가 이미지 크기와 무관한 이유는?">

**답:** 파라미터는 필터(예: 3×3×채널)에만 있고, 그 필터 하나가 모든 위치에 공유되어 쓰이기 때문이다. MLP는 위치마다 별도 가중치를 두어 픽셀 수에 비례해 폭발한다. → [13장](/book/13-cnn)

</Quiz>

<Quiz id="p4-03" q="'공간은 줄이고 채널은 늘린다'는 CNN의 리듬이 표현 학습 관점에서 자연스러운 이유는?">

**답:** 층을 오를수록 '정확히 어디'(위치 정보)는 덜 중요해지고 '무엇이 있나'(패턴의 종류)가 중요해진다. 풀링/스트라이드로 공간을 요약하고, 채널을 늘려 더 많은 종류의 추상 패턴을 담는다 — 모서리→부품→사물의 위계. → [13장](/book/13-cnn)

</Quiz>

<Quiz id="p4-04" q="전이학습의 레시피와, 데이터 양에 따른 동결 전략은?">

**답:** 사전학습 모델의 마지막 분류 층만 내 클래스 수로 교체. 데이터가 아주 적으면 몸통 동결(특징 추출기), 좀 있으면 몸통도 아주 작은 학습률로 미세조정. 실무 시각 문제의 9할이 전이학습이다. → [13장](/book/13-cnn)

</Quiz>

<Quiz id="p4-05" q="탐지에서 '상자 개수를 미리 모른다'는 문제를 표준 해법이 어떻게 푸는가? NMS는 왜 필요한가?">

**답:** 후보 상자를 화면 가득 깔고 각 후보에 대해 '물체 있는가 + 클래스 + 좌표 보정'을 예측 — 가변 개수 문제를 고정 개수의 분류+회귀로 바꾼다. 부작용으로 같은 물체에 상자가 수십 개 겹치므로, 확신도 최고를 채택하고 많이 겹치는(IoU 큰) 후보를 지우는 NMS로 정리한다. → [14장](/book/14-vision-tasks)

</Quiz>

<Quiz id="p4-06" q="U-Net의 스킵 연결이 없으면 어떤 결과가 나오며 왜인가?">

**답:** 물체는 맞추되 경계가 뭉개진다. 인코더가 공간을 줄이며 '어디'를 버렸는데, 디코더가 추상 정보만으로 복원하기 때문. 스킵 연결이 얕은 층의 위치 정보를 디코더에 직접 건네 경계를 살린다 — 잔차 연결과 같은 '정보의 지름길' 사상. → [14장](/book/14-vision-tasks)

</Quiz>

<Quiz id="p4-07" q="ViT가 중간 규모 데이터에서는 CNN에 지고 대규모에서는 이기는 현상이 말해 주는 원칙은?">

**답:** 귀납 편향과 데이터 양은 교환 관계다. 데이터가 적으면 상식(지역성 등)을 구조에 새겨야 하고, 데이터가 넘치면 구조를 비우고 데이터가 말하게 하는 편이 낫다. → [14장](/book/14-vision-tasks)

</Quiz>

<Quiz id="p4-08" q="파형을 그대로 분류기에 넣기 어려운 이유와 스펙트로그램의 해법은?">

**답:** 파형의 개별 압력값에는 의미가 거의 없다(시작이 1ms만 밀려도 숫자가 전부 바뀜). 의미는 주파수 성분에 있으므로, 짧은 창마다 성분 분석(푸리에 변환)을 쌓아 시간×주파수의 2차원 그림으로 바꾼다. → [15장](/book/15-audio)

</Quiz>

<Quiz id="p4-09" q="'표현이 바뀌면 도구가 이식된다'를 오디오로 설명하라.">

**답:** 로그-멜 스펙트로그램은 사실상 단채널 이미지라서, CNN·증강(SpecAugment)·전이학습 등 이미지 도구가 그대로 통한다. 어려운 것은 학습이 아니라 표현이었다. → [15장](/book/15-audio)

</Quiz>

<Quiz id="p4-10" q="음성 인식의 고유 난제와 현대적 해법은?">

**답:** 입력(프레임 수백)과 출력(글자 수십)의 길이가 다르고 정렬 정보가 없다. 인코더가 스펙트로그램을 읽고 디코더가 글자를 한 자씩 생성하는 인코더-디코더 구조(Transformer)로 풀며, 실무는 사전학습된 Whisper가 기본기. → [15장](/book/15-audio)

</Quiz>
