## 개발

[Astro](https://astro.build) 7 + React 19 + MDX로 만든 정적 사이트다. 3D는 three.js와 React Three Fiber, 검색은 Pagefind를 쓰고, `main`에 머지되면 GitHub Actions가 GitHub Pages로 배포한다.

```bash
npm ci            # Node 24 이상
npm run dev       # http://localhost:4321/AI/
npm run build     # 정적 사이트 + 검색 색인 → dist/
```

원고는 `src/content/`(MDX), 시각화는 `src/components/viz/`, 시각화 등록부는 `src/data/viz/`, 용어 사전은 `src/data/glossary/`에 있다. 시각화를 추가하는 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)에 정리했다.
